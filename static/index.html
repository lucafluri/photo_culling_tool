Shortcuts — left-hand, ESDF layout

Navigate

  • ESDF move (or arrows)
  • Home/End first / last
  • G / Enter loupe view
  • Esc back / close
  • T cycle filter
  • V this help

Mark

  • W keep  R reject  Q clear flag
  • 1–5 stars  ` 0 stars
  • U undo last mark
  • flags auto-advance to next

Compare

  • Space add/remove from compare set
  • C open compare (set, or current+next)
  • X clear compare set
  • SDF (≤3 in compare) keep that one, reject rest, close
  • >3 selected → vote ←/S vs →/F to find the best

Edit multiple (grid)

  • Space-select several, Ctrl+V or 📋 Paste edits applies the last-copied edits to all of them
  • 🎛 Preset dropdown + Apply does the same with a saved preset
  • no selection → applies to the highlighted photo

Loupe / Compare

  • scroll / ED zoom (synced)
  • drag pan (synced in compare)
  • SF prev / next (loupe)
  • Z / dblclick reset zoom
  • marking works here too

Edit (loupe sidebar)

  • sections: History, Presets, Histogram, Info, Crop & Rotate, Lens, Light, Color, Detail, Retouch, Effects — click a header to collapse it
  • Tab hides/shows the whole sidebar (or click the ◂ tab)
  • C crop · P retouch · O original ⇄ edited · I EXIF · G grid · H histogram
  • crop takes an aspect ratio (1:1, 3:2, 16:9, original…) that constrains the drag
  • alignment grid shows by default, forces on while straightening
  • Lens: barrel/pincushion distortion, chromatic aberration and keystone — the frame stays full, no black corners to crop off
  • Light: exposure in stops, highlights, shadows, whites, blacks
  • Color: WB red/blue, vibrance, saturation, B&W · Detail: clarity, sharpness, noise reduction · Effects: vignette, grain, border
  • Retouch (P): the ring under the cursor is the brush. Brush paints over whatever you drag across; Spot fixes one blemish per click and lets you drag out the source. The source area is found for you either way. Heal takes the target's colour and shading, Clone copies pixels as they are. Click a painted region to remove it, brush past the edge of the frame freely, and pan with the middle button while retouching
  • click any line in the histogram's change list to switch that one adjustment off, click again to bring it back unchanged
  • histogram overlays the original's tone curve in white and lists every active edit — how auto-levels (or anything else) actually changed the photo
  • a RAW+JPEG pair edits as one photo; the stack is mirrored onto both files, and Export can write the JPEG, a JPEG rendered from the RAW, the RAW itself and an .xmp sidecar in any combination
  • Info offers a JPEG / RAW switch for a photo that has a negative. In RAW view everything works off the negative: every adjustment, O, navigation, Save copy, and the size and file rows. Ticking “JPEG rendered from the RAW” in Export flips it to RAW so what you see is what gets written (first load takes a few seconds, then it is cached; compare stays on the fast previews)
  • white balance: independent Red/Blue channel sliders — with Auto on, the histogram also estimates the Fuji WB shift (R/B) needed to match what Auto proposed
  • every slider has tick marks and a type-in numeric field
  • sliders with a CSS equivalent preview as you drag; the rest (highlights, lens, vignette…) render a server draft on each pause
  • double-click a slider to reset it
  • Ctrl+Z / Ctrl+Y undo / redo (per photo)
  • Ctrl+C / Ctrl+V copy / paste this photo's edits
  • Preset: Save names the current edits, Load applies one
  • 💾 saves an edited copy next to the original
  • non-destructive — Reset reverts, export bakes
